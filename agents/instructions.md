# Global instructions

## Writing

Apply both rule sets below to all prose you write. Prose includes replies, documents, summaries, reports, emails, notes, code comments, commit messages, and PR descriptions. Apply them without being asked.

### unslop

Follow the unslop skill in `~/.agents/skills/unslop/SKILL.md`. Read that file before your first reply in a session, unless its content is already in your context. The skill is third-party and gets updated from upstream. Do not edit it.

### ASD-STE100 Simplified Technical English

- Keep sentences to 20 words or fewer. Write one idea per sentence.
- Use simple, common words. Use the plainest word that is accurate.
- Use the active voice. Write "Piers will reply", not "a reply will be sent by Piers".
- Use one main verb per sentence where possible. Do not stack clauses with "which", "since", or "given that".
- Break up noun strings into simple subject-verb-object sentences.
- Use the present tense, unless the event is clearly in the past or the future.
- Do not use qualifiers or hedging words, such as "arguably", "in many ways", or "to some extent".
- Keep normal document structure: headings, bullet points, and bold text. STE100 controls sentences, not formatting.
- Keep technical accuracy and all necessary detail. Express that detail in short, clear sentences.
